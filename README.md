# 주요정보통신기반시설(주통기) 기술적 취약점 진단 — Linux

KISA **『주요정보통신기반시설 기술적 취약점 분석·평가 상세가이드』** 기준에 따라 Linux 서버를 자동 점검하고, 취약 항목을 직접 조치·재점검한 프로젝트입니다.

> EST 인프라보안 과정 3차 개별 프로젝트 · 점검 대상: 자체 구축 랩(ESXi) 서버

---

## 1. 개요

| 항목 | 내용 |
|---|---|
| **점검 기준** | KISA 주통기 기술적 취약점 분석·평가 가이드 (U-01 ~ U-67) |
| **점검 대상** | Rocky Linux 서버 (MASTER, keepalived+haproxy 이중화) |
| **점검 방식** | 셸 스크립트 자동 점검 → 양호/취약 자동 판정 → 수동 검증 → 조치 → 재점검 |
| **점검 범위** | 계정 / 파일·디렉터리 / 서비스 / 로그 관리 (기술적 점검) |

## 2. 점검 결과 요약

| 분야 | 점검 | 양호 | 취약 | 해당없음 |
|---|---|---|---|---|
| 계정 관리 | 13 | 7 | 6 | 0 |
| 파일·디렉터리 관리 | 20 | 16 | 3 | 1 |
| 서비스 관리 | 30 | 19 | 6 | 5 |
| 로그 관리 | 3 | 3 | 0 | 0 |
| **합계** | **66** | **45** | **15** | **6** |

**취약 15건 중 14건 조치 완료**, 1건(U-28 호스트 방화벽)은 운영 리스크를 고려한 **계획 변경 권고**로 처리.

### 주요 조치 사례
- **U-01** root 원격 접속 차단 (`PermitRootLogin no`)
- **U-13** 취약 해시(MD5 `$1$`) → **yescrypt `$y$`** 재해시 (36개 계정)
- **U-40** NFS `no_root_squash` → `root_squash`
- **U-52** 평문 Telnet 서비스 비활성화

## 3. 자동화 스크립트 구성

| 스크립트 | 점검 범위 |
|---|---|
| `scripts/Account_check.sh` | 계정 관리 (U-01~U-06) |
| `scripts/File_check.sh` | 파일·디렉터리 관리 (U-14~U-30) |
| `scripts/Service_check.sh` | 서비스 관리 (U-34~U-63) |
| `scripts/Rest_check.sh` | 나머지 (계정 U-07~13 / 파일 U-28~33 / 로그 U-65~67) |

### 사용법
```bash
sudo bash scripts/Account_check.sh
```
- **읽기 전용** — 점검만 수행하며 설정을 변경하지 않음
- 양호/취약을 **자동 판정**하고 결과를 `/root/check/log/*.csv`로 저장
- 조치 전·후 두 번 실행해 **개선 효과를 검증**

---

## 4. 오탐(False Positive) 처리 — 자동화의 한계 보완

자동 점검 결과를 그대로 신뢰하지 않고, **오탐 5건을 식별·검증**하여 바로잡았습니다.

| 분야 | 오탐 | 처리 방식 |
|---|---|---|
| 파일 U-15 | 소유자 없는 파일 = 컨테이너 레이어 | 스크립트에서 `containerd` 경로 제외 |
| 파일 U-24 | 심볼릭 링크 권한 | `-type f`로 링크 제외 |
| 파일 U-26 | `/dev/shm` 공유메모리 | `/dev/shm` 경로 제외 |
| 서비스 U-42 | rpcbind = NFS 의존 서비스 | NFS 구동 시 양호로 판별 |
| 서비스 U-47 | 메일 relay 내부망 제한 | 실제 적용값(`postconf`) 기준 판별 |

→ 이 저장소의 스크립트는 **오탐 판별 로직이 반영된 개선 버전**입니다.

---

## 5. 이중화(HA) 환경 고려

대상 서버는 `keepalived(VRRP)` + `haproxy`로 가용성이 이중화되어 있어, 조치 시 **서비스 중단·HA 통신 영향이 없는 설정 변경 위주**로 수행했습니다. U-28(호스트 방화벽)은 Docker의 iptables 제어·NFS 동적 포트·VRRP 의존성을 식별하여 **계획된 변경으로 권고**했습니다.
